Al ejecutar el comando node server.js, el servidor inicia correctamente y queda esperando solicitudes en el puerto 3000. En la terminal aparece el mensaje "Servidor ejecutándose en puerto 3000". Al visitar la ruta /estado en el navegador, se muestra un objeto JSON indicando que el servidor está funcionando y que el servicio corresponde a una API comunitaria.

Ejemplo de respuesta:

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
