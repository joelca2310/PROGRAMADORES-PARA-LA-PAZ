Sistema operativo:
Es el software que administra los recursos del computador y permite ejecutar aplicaciones. También controla el funcionamiento del hardware.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para crear servidores y aplicaciones web.

Aplicación server.js:
Es el archivo donde se escribe el código del servidor. Define las rutas y la forma en que responde a las solicitudes.

Puerto:
Es el punto de comunicación por donde el servidor recibe las solicitudes de los usuarios. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que muestran la actividad y los eventos del servidor. Ayudan a detectar errores y supervisar el funcionamiento de la aplicación.
